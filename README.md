A faithful Node interpreter for make.fun's tiny stack ISA: 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exact exit codes.

## Run it

```sh
node main.ts
```

Reads every instance under `/input/<id>/` (`$MAKEFUN_INPUT_DIR`) and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` (`$MAKEFUN_OUTPUT_DIR`).
